# Calemaru テストスイート

このディレクトリには、Calemaruアプリケーションの包括的なテストスイートが含まれています。

## 概要

Calemaruは複数のカレンダーサービスからのデータを統合し、一元管理できるカレンダーアプリケーションです。このテストスイートは以下の機能を検証します：

- **カレンダー管理**: イベントの作成・編集・削除
- **ファイルインポート**: ICS、CSV、JSON形式のサポート
- **OCR機能**: 画像からテキストを読み取ってイベント化
- **複数カレンダーソース**: Google、Outlook、Apple、ローカルカレンダーの統合

## テスト構成

### 1. 型定義テスト (`types/`)
- `calendar.test.ts`: カレンダー関連の型定義の検証
- インターフェースの構造とプロパティの確認

### 2. ユーティリティテスト (`utils/`)
- `calendarImporter.test.ts`: ファイルインポート機能の検証
  - ICSファイルパーサー
  - CSVファイルパーサー
  - JSONファイルパーサー
- `imageCalendarParser.test.ts`: OCR機能の検証
  - 画像からのテキスト抽出
  - イベントデータの生成

### 3. フックテスト (`hooks/`)
- `useCalendar.test.ts`: カレンダー管理フックの検証
  - 状態管理
  - イベント操作
  - カレンダーナビゲーション

### 4. 統合テスト (`integration/`)
- `calendarIntegration.test.ts`: エンドツーエンドのワークフロー検証
  - 複数形式のファイルインポート
  - データの一貫性
  - エラーハンドリング

## セットアップ

### 依存関係のインストール

```bash
cd test
npm install
```

### テストの実行

```bash
# 全テストの実行
npm test

# ウォッチモードでの実行
npm run test:watch

# カバレッジレポートの生成
npm run test:coverage

# 特定のテストカテゴリの実行
npm run test:utils      # ユーティリティテストのみ
npm run test:hooks      # フックテストのみ
npm run test:types      # 型チェックのみ
```

## 問題点と改善提案

### 発見された問題

1. **ICSパーサーの制限**
   - 複雑なICSファイルの処理が不完全
   - タイムゾーン情報の無視
   - 繰り返しイベントの未対応

2. **CSVパーサーの柔軟性**
   - 列名の自動認識が限定的
   - 日付形式の厳密な検証不足
   - エラーメッセージの詳細性不足

3. **OCR機能の制約**
   - 英語のみ対応（日本語未対応）
   - 複雑なレイアウトの処理困難
   - 精度向上の余地

4. **エラーハンドリング**
   - 一部のエラーケースで適切なフォールバック不足
   - ユーザーフレンドリーなエラーメッセージの不足

### 推奨改善事項

1. **パーサーの強化**
   - より柔軟な列名マッピング
   - タイムゾーン対応の追加
   - バリデーション機能の強化

2. **OCR機能の拡張**
   - 多言語対応（日本語、中国語など）
   - 機械学習による精度向上
   - 複数レイアウトパターンの対応

3. **エラー処理の改善**
   - 詳細なエラーログ
   - ユーザー向けエラーメッセージ
   - 部分的な成功の適切な処理

4. **パフォーマンス最適化**
   - 大容量ファイルの処理改善
   - 非同期処理の最適化
   - メモリ使用量の削減
